## Fixed

- **Controllers work again on the desktop client.** Your controller paired and the app responded to it, but games saw no controller at all. The virtual controller now starts correctly, and the existing app controls work again.

  This hit almost everybody, because it hit the controller type Slipstream emulates by default. If you had gone into settings and explicitly chosen DualShock 4, Xbox 360, DualSense Edge or Steam Deck, yours kept working the whole time — only the default was broken. Both 0.22.0 and 0.22.1 are affected; 0.21.0 and earlier are not.
