Wire-compatible with 0.21.x and 0.22.0 — hosts are untouched by this release, and everything already paired keeps working.

**If you installed 0.22.0 on Linux, update now:** this fixes connecting, which 0.22.0 broke on the desktop client. Coming from 0.21.0, you get everything 0.22.0 added — settings profiles, `slipstream://` links, the `slipstream` command, Gaming-Mode HDR — plus these fixes.

## Fixed

- **Connecting works again on Linux.** 0.22.0 accidentally shipped the wrong program as the piece that renders your stream, so the stream window never appeared. Mac, iPhone, iPad, Apple TV and Android were not affected. Nothing about how streams work has changed — 0.22.1 delivers what 0.22.0's notes promised.
- **A stream that can't start now tells you why.** If the stream window exits without reporting anything, the desktop client now shows its exit code instead of silently returning to your hosts — a broken install is a message, not a mystery.

## Improved

- **Every `slipstream` command now explains itself.** `slipstream help launch` — or `--help` after any command — prints that command's flags, what lands where, and what each exit code means, so a script author never has to read the source. `slipstream help` still lists everything.
- **`slipstream reachable` stopped scolding.** Probing an address you haven't saved is exactly what the command is for; it no longer suggests pairing first before answering.

## Under the hood (for developers)

- The 0.22.0 breakage came from a stray copy of the GTK shell's sources landing in the session crate and overwriting its `main.rs`, the `[[bin]]` entry point. `slipstream-session` was built from the wrong file, while the shell's `--connect` handling execs `slipstream-session` — that is, itself. Every compile gate stayed green because the wrong program compiled perfectly.
- CI now *runs* what it ships: an integration test spawns the built `slipstream-session` against a refusing port and fails unless a stdout-contract line answers; another runs `slipstream` over its help surface. `slipstream-cli` also joined the build, clippy, format and test gates.
- The desktop shell's `SpawnEvent::Exited` now carries the child's exit code; a nonzero exit with no contract line gets a banner naming it. Codes 0 (window closed) and -1 (our own kill) stay silent as before.
- No wire or ABI changes: wire protocol 2 and C ABI 13 remain identical to 0.22.0.
