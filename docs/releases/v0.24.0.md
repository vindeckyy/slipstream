# Slipstream 0.24.0

Slipstream 0.24.0 brings the streaming host to Windows, alongside web console polish and
hardening across the Linux host paths.

## Supported downloads

- Linux x86_64 host archive
- Steam Deck client Flatpak
- Steam Deck Decky plugin zip
- Android clients continue on the rolling `v0.23.0-public` release

## Windows host (new)

A Windows PC can now be the streaming host. Build `slipstream-host` and `slipstream-tray` on
Windows (MSVC or GNU toolchain); the Linux, Android, and Steam Deck clients connect to it the
same way they connect to a Linux host. See the [Windows host guide](https://vindeckyy.github.io/slipstream/docs/windows-host).

- **Capture:** Windows Graphics Capture with DXGI fallback (`SLIPSTREAM_CAPTURE_METHOD` selects
  `auto`, `wgc`, or `dxgi`); the pointer is embedded in the frame.
- **Encode:** NVIDIA NVENC over D3D11 when the driver answers, with the honest codec list from the
  driver probe; openh264 H.264 software fallback otherwise.
- **Display:** Mirror a monitor by default, or plug a RustDesk indirect display when that driver
  is installed.
- **Audio:** WASAPI loopback capture with resample/remap to 48 kHz.
- **Input:** `SendInput` keyboard/mouse/pen injection with native Unicode text; host cursor hides
  during sessions. (A virtual gamepad is not wired up yet.)
- **Clipboard:** Text, HTML, RTF, and PNG in both directions.
- **Service & tray:** Run headless under the Service Control Manager (`sc create slipstream-host`),
  with a system-tray icon for service state, console deep links, and pairing approvals.
- **QoS:** MMCSS and qWAVE cover the low-latency profile.

AMD AMF and Intel Quick Sync are not encode backends on Windows; requesting them fails loudly
instead of silently substituting.

## Web console

- Library empty state redesigned as an intentional dashed affordance.
- Getting Started and pairing PIN presentation refined.
- Design tokens, shell density, and chart palette reworked with light/dark parity.

## Host hardening

- Cursor, frame-queue, and video paths hardened (TV-only cursor visibility, queue occupancy
  reservation, defensive cropping of unaligned frames on older drivers).
- Settings: shared guidance, dependency-aware configuration, safer saves.
- Clippy 1.96 hygiene across the workspace.

## Operations

- Release artifacts include SHA-256 checksums, third-party notices, SBOM, and build provenance
  attestations.
- The repository scans full Git history for secrets and validates first-party links, generated
  API files, packaging metadata, and pinned GitHub Actions.

See the [installation guide](https://vindeckyy.github.io/slipstream/docs/install) and
[security policy](https://github.com/vindeckyy/slipstream/security/policy) before exposing a host
outside a trusted LAN.
