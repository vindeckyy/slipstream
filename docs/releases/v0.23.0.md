# Slipstream 0.23.0

Slipstream 0.23.0 is the first public release of the Linux streaming host and its supported client
paths.

## Supported downloads

- Linux x86_64 host archive
- Android preview APK for arm64-v8a, armeabi-v7a, and x86_64
- Steam Deck client Flatpak
- Steam Deck Decky plugin zip

The Android preview uses its own rolling GitHub release. The Decky plugin and Flatpak currently use
manual installation rather than a public package feed.

## Host and protocol

- Native Slipstream sessions use authenticated pairing, encrypted control traffic, and negotiated
  capabilities.
- The Linux host supports NVIDIA, AMD, and Intel encoding paths, subject to the installed driver and
  compositor.
- Optional GameStream compatibility is available for Moonlight clients. It must be enabled
  explicitly and cannot run beside another Moonlight-compatible host on the same machine.
- The web console covers pairing, sessions, library management, display configuration, logs,
  settings, and plugin-runner administration.

## Clients

- The Android preview supports phones, tablets, Android TV, and Google TV.
- The Linux client can be installed as a Flatpak on Steam Deck and other Linux desktops.
- The Decky plugin discovers hosts, handles pairing, and launches the installed Linux client from
  Gaming Mode.

## Operations

- Release artifacts include SHA-256 checksums and third-party notices.
- The repository now scans full Git history for secrets and validates first-party links, generated
  API files, packaging metadata, and pinned GitHub Actions.
- Public installation docs no longer depend on unpublished package registries or update feeds.

See the [installation guide](https://vindeckyy.github.io/slipstream/docs/install) and
[security policy](https://github.com/vindeckyy/slipstream/security/policy) before exposing a host
outside a trusted LAN.
