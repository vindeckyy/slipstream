# Support

Slipstream is self-hosted software. Start with the [documentation site](https://vindeckyy.github.io/slipstream/),
especially the [quick start](https://vindeckyy.github.io/slipstream/docs/quickstart/),
[troubleshooting](https://vindeckyy.github.io/slipstream/docs/troubleshooting/), and
[security](https://vindeckyy.github.io/slipstream/docs/security/) pages.

Use [GitHub Issues](https://github.com/vindeckyy/slipstream/issues) for reproducible bugs and
feature requests. Include the Slipstream version, Linux distribution, compositor, GPU, client,
connection type, and the smallest useful log excerpt. Remove hostnames, addresses, tokens, and
other private data before posting.

Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities. Do not put exploit
details in a public issue.
